Interactive Architecture

Animated Quantune Workflow

Watch how Quantune transforms raw domain JSONL datasets into production-grade Small Language Models with automated response-loss masking.

pipeline_execution_sim.py · Quantune SDK v0.2.0 
import quantune as qt

# 1. Ingest and perform 12-point quality check
dataset = qt.ingest("customer_support.jsonl")
diag = qt.validate(dataset)  # Grade: A+ (Score: 98/100)

# 2. Hardware-aware SLM recommendation
rec = qt.recommend(task="conversation", hardware="T4")
print(f"Target: {rec.model_name} (LoRA r=16, alpha=16)")

# 3. Train with Unsloth response-loss masking
trainer = qt.train(
    model_id="unsloth/Phi-4-mini-instruct",
    mask_prompt_loss=True,  # 70% VRAM saving!
    epochs=3,
    lr=2e-4
)
print("Quantune training job converged successfully!")
